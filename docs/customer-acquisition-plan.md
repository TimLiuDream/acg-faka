# Dreamer Labs 获客计划

更新时间：2026-09-12

## 目标

在控制获客成本和平台风险的前提下，为 Dreamer Labs 建立可持续的客户来源。现阶段优先利用已有客户、个人内容影响力和垂直社群，不急于大规模购买广告流量。

渠道优先级：

1. 老客转介绍
2. 内容获客
3. 垂直社群与创作者合作
4. 搜索流量
5. 小额付费广告测试

## 产品与合规边界

优先推广由用户使用自己账号完成的自助兑换服务，并明确说明是否需要提供账号信息、交付形式、退款条件和质保范围。

成品账号、共享账号、账号凭证交接和代操作的风险更高。公开推广前需要持续核对相关产品的最新服务条款：

- [OpenAI 使用条款](https://openai.com/policies/row-terms-of-use/)
- [OpenAI 账号共享政策](https://help.openai.com/en/articles/10471989-openai-account-sharing-policy)
- [OpenAI 服务额度条款](https://openai.com/policies/service-credit-terms/)
- [Anthropic 透明度与执行说明](https://www.anthropic.com/transparency/system-trust-reporting)
- [Google Ads 政策](https://support.google.com/google-ads/answer/6008942?hl=en)

网站和宣传材料应避免无法证明的“百分百稳定”“绝不封号”“零风险”等承诺，也不能隐藏付款、退款、订阅期限或交付限制。

## 一、老客转介绍

每笔已付款订单生成专属邀请链接或邀请码。

建议规则：

- 新客户获得固定金额优惠券。
- 邀请人获得余额、优惠券或下次续费折扣。
- 订单完成且超过售后观察期后再发放奖励。
- 退款、异常支付或重复账户不计算奖励。
- 在订单结果页、发货邮件、兑换成功页和个人中心展示邀请入口。

需要统计：邀请链接点击量、注册量、付款订单数、奖励成本、退款率和实际获客成本。

## 二、个人内容获客

以“白日梦想家 / TimLiu”为内容主体，Dreamer Labs 作为产品和服务承接站。内容以解决真实问题为主，商品推广为辅，建议内容与销售比例保持在约 4:1。

可持续选题：

- Codex 与 Claude Code 如何选择
- ChatGPT Plus 开通前需要检查什么
- Claude Pro、Max 5X、Max 20X 的区别
- 卡密兑换完整教程
- 支付失败和账号资格不符合时如何处理
- AI 编程的实际工作流
- 新模型、新功能和价格变化
- Dreamer Labs 服务、库存和售后更新

每篇内容只保留一个清晰行动入口，例如“查看完整教程”或“进入 Dreamer Labs 自助开通”。避免同一篇内容同时要求关注、转发、加微信和购买。

建议渠道：

- X / Twitter：短教程、产品变化、真实使用记录和服务公告。
- 小红书：步骤图、购买前检查清单和常见问题。
- B 站：完整演示、工具对比和故障处理。
- 知乎、公众号：可被搜索引擎长期收录的深度指南。

## 三、搜索内容与落地页

为高意向问题建立独立页面，而不是让所有搜索流量直接进入商品列表。

建议页面：

- `/guide/chatgpt-plus`
- `/guide/codex`
- `/guide/claude-pro`
- `/guide/claude-max`
- `/guide/payment-failed`
- `/guide/redeem-card`

每个页面应包含：适用对象、开通条件、产品区别、价格和期限、完整步骤、常见失败原因、售后范围以及对应商品入口。

标题和正文重点覆盖用户真实搜索的问题，例如“区别、价格、资格、开通步骤、支付失败、兑换失败”，避免只堆叠“低价、代充”等交易词。

## 四、社群与创作者合作

优先寻找 AI 编程、独立开发、出海工具、效率工具和开发者相关的小型垂直社群。

合作材料：

- 专属优惠码
- 带渠道参数的推广链接
- 按实际付款订单结算的佣金
- 可直接发布的图文介绍
- 真实测试订单或操作演示
- 清楚的售后联系人和问题处理流程

合作佣金可以从成交金额的 5%–15% 小范围测试，根据毛利、退款率和客户质量调整。不要按点击量结算，也不要在无关群组批量发送广告。

## 五、网站信任建设

可以在不泄露客户隐私的情况下展示：

- 累计完成订单数
- 最近 24 小时发货数量
- 平均发货时间
- 支付成功率
- 商品期限和交付方式
- 退款与质保边界
- 是否需要账号密码
- 联系支持入口

所有统计数字应直接来源于系统数据，并说明统计口径。

## 六、续费与复购

月卡商品应把复购作为主要增长来源之一。

可实施功能：

- 到期前第 5 天和第 2 天发送续费提醒。
- 订单页增加“一键再次购买”。
- 为正常完成的老客户提供续费优惠。
- 根据已购商品提供相关教程和使用建议。
- 用户可以关闭营销和续费提醒。

## 七、数据漏斗

目前已有首页和商品详情浏览量。下一步需要增加渠道与订单转化统计：

1. 首页浏览
2. 商品详情浏览
3. 开始填写订单
4. 创建订单
5. 进入支付
6. 支付成功
7. 发货成功
8. 退款或售后

渠道字段建议：

- `utm_source`
- `utm_medium`
- `utm_campaign`
- 首次来源域名
- 邀请码或合作方编号

只做渠道和事件级统计，不采集不必要的个人隐私。后台应能按日期、商品和渠道查看：

- 商品详情访问率
- 下单转化率
- 支付成功率
- 发货成功率
- 客单价
- 退款率
- 新客与复购占比
- 单个付费客户获客成本

## 八、付费广告原则

在自然渠道能够稳定成交、落地页信息完整且能计算转化率之前，不进行大额广告投放。

开始测试时：

- 每次只测试一个渠道、一个商品和一个落地页。
- 使用精确关键词和明确受众。
- 设置每日预算和获客成本上限。
- 至少观察完整的点击、下单、付款和退款链路。
- 不通过审核时先检查产品与平台政策，不频繁更换账号或规避审核。

## 30 天执行计划

### 第 1 周：打通数据

- 增加 UTM 和来源渠道记录。
- 增加完整的购买转化漏斗。
- 为每个商品核算售价、成本、毛利和可承受获客成本。
- 准备邀请返利规则。

### 第 2 周：生产内容

- 发布 3 篇完整购买或兑换指南。
- 发布 8–10 条短内容。
- 每个商品页补齐期限、条件、交付和售后说明。
- 将内容链接统一接入渠道追踪。

### 第 3 周：合作测试

- 联系 20 个垂直社群或小型创作者。
- 争取完成 3 个可追踪的合作测试。
- 记录每个合作方的点击、成交、退款和复购数据。

### 第 4 周：筛选渠道

- 保留转化率和利润表现最好的两个渠道。
- 停止只有流量、没有付款的渠道。
- 优化访问量高但下单率低的商品页。
- 在产品与平台政策允许的前提下，再考虑小额广告测试。
